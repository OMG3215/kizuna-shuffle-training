# KIZUNA SHUFFLE TRAINING

自宅でできる筋トレメニューをランダムに抽選するWebアプリ。

**URL:** https://OMG3215.github.io/kizuna-shuffle-training/

---

## 使い方

1. **レベル選択** — EASY / MIDDLE / HARD から今日のコンディションに合わせて選ぶ
2. **スタート** — トレーニングメニューと回数がシャッフルされる
3. **ストップ** — 種目が確定する（約1/5の確率でミステリー「?」が出現）
4. **タイマー開始** — 60秒カウントダウン（＋30秒 / －30秒で調整可能）
5. **完了** — アラート音が鳴ったら終了。次のメニューを引く

---

## 収録トレーニング（18種）

| カテゴリ | 種目 |
|---|---|
| 腕・胸 | 腕立て伏せ |
| 腹筋 | クランチ、レッグレイズ、バイシクルクランチ、バタ足腹筋、クロス腹筋、腸腰筋レッグアップ |
| 体幹 | プランク、サイドプランク、お尻歩き、スパイダー |
| 脚 | スクワット、ランジ、カーフレイズ、ヒップリフト、ヒンジスクワット |
| 全身 | バーピー、マウンテンクライマー |

## レベル別回数

| レベル | 回数目安 |
|---|---|
| EASY | 〜 30 回 |
| MIDDLE | 31 〜 50 回 |
| HARD | 51 〜 200 回 |
